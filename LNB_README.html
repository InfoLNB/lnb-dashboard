📘 Documentation – LNB GROUP APP

📂 Fichiers inclus

  • index.html – Page d’accueil simple pour rediriger vers Admin ou Employé
  • admin-dashboard.html – Tableau de bord administrateur
  • employee-dashboard.html – Planning simplifié pour employés
  • rapport-intervention.html – Formulaire complet pour interventions
  • project-detail.html – Fiche détaillée de chaque projet
  • style.css – Feuille de style commune
  • LNB_README.html – Ce fichier de documentation

📌 Fonctionnalités clés

  • Bouton ➕ pour ajouter une intervention (modale ou formulaire dédié)
  • Archivage rapide des projets (📁 Archives en bas de page admin)
  • Connexion aux secteurs : Yachting, Painting, Cover, Cleaning
  • Statuts colorés pour les projets (En devis, En cours, Terminé, etc.)
  • Formulaire intervention avec upload + GPS + matériel

🚀 Mise en ligne

Pour déployer le projet :

  1. Décompressez le fichier .zip
  2. Créez un repo GitHub ou Render
  3. Glissez-déposez les fichiers dans le repo ou utilisez un client FTP/terminal
  4. Activez GitHub Pages (si frontend statique) ou configurez Render (pour backend email)
